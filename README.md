# Cox Concierge Public

Public, login-free information and SMS-consent pages for Cox Concierge Services.

This repository intentionally excludes the owner dashboard, customer records, payment processing, databases, and service credentials. It exists so customers and messaging-compliance reviewers can directly access the onboarding disclosure, privacy policy, and service/texting terms.

## Public routes

- `/`
- `/onboarding/`
- `/privacy/`
- `/terms/`

The onboarding page demonstrates the consent flow but does not store or transmit entered information.
